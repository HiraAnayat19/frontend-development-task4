# Music Player – Frontend Development Task 4

This project is a simple and interactive **Music Player** created using HTML, CSS, and JavaScript.

### Features

* Play and pause music
* Next and previous song controls
* Music player interface
* Song progress bar
* Volume control
* Responsive and user-friendly design

### Technologies Used

* HTML
* CSS
* JavaScript



This project was developed as part of my **Frontend Development Internship – Task 4**.
